# C# Learning Repository

A collection of C# programs created while learning the fundamentals of C# and .NET. This repository contains examples, practice programs, and problem-solving exercises covering core programming concepts.

---

## 📖 About

This repository is designed to strengthen C# programming skills through hands-on coding. It includes beginner to intermediate examples that demonstrate object-oriented programming, collections, file handling, exception handling, and other important C# concepts.

---
